# AZ Portfolio

Personal developer portfolio for **Adrian Zalewski**, a Senior Full Stack PHP Developer focused on building web applications across a diverse range of technologies, frameworks, platforms, and deployment environments.

The portfolio demonstrates experience spanning traditional server-side development, modern JavaScript frameworks, CMS platforms, APIs, databases, Linux server administration, and automated CI/CD workflows.

## Overview

AZ Portfolio is a React application built with **Vite** and designed to showcase Adrian Zalewski's professional development experience, technical projects, ability to work across different technology stacks, and more.
